# Visualization Outputs

This directory contains visualization outputs from the Dartboard pipeline.

## Directory Structure

```
viz/
├── texas/          # Texas region visualizations
├── new_york/       # New York region visualizations
└── tests/          # Test and development visualizations
```

## Visualization Types

### Clustering Visualizations

Generated by `pipelines/build_clustered_substations.py`:

- **`{region}_clusters.png`** - Shows cluster members (small dots) colored by cluster, with cluster centers as large stars
- **`{region}_clustering_comparison.png`** - Shows original load nodes (gray) vs final cluster centers (red stars)
- **`{region}_substations.png`** - Shows final bus substations colored by load (MW)

### Load Node Visualizations

Generated by earlier pipeline stages:

- **`{region}_load_nodes.png`** - Original Census load nodes colored by population
- **`{region}_gen_nodes.png`** - EIA generator locations colored by fuel type
- **`{region}_overlay.png`** - Combined view of load and generation nodes

### Test Visualizations

Located in `tests/` subdirectory:

- Test runs with smaller datasets or different parameters
- Development and verification plots

## Regenerating Visualizations

To regenerate all clustering visualizations:

```bash
python3 pipelines/build_clustered_substations.py
```

To run tests:

```bash
python3 pipelines/test_clustering_small.py
python3 pipelines/test_clustering_medium.py
```

## File Naming Conventions

- `texas_*` or `tx_*` - Texas region
- `new_york_*` or `ny_*` - New York region
- `test_*` - Test/development outputs
