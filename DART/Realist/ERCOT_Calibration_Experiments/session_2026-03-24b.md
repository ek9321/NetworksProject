8. **Edge-splice (Fix 8):** 129 low-degree substations spliced into nearby edges they clearly belong on. Principled heuristic: splice distance < 2 km AND < 30% of edge length, projection 10-90% along edge, same voltage tier.

### Key discovery: 66.4% bridge ratio → 18.4%
The 138 kV network was 2/3 tree-like (66.4% bridges). This was THE root cause of load shedding — large subtrees funneled massive load through single narrow branches. The edge-splice fix reduced this to 18.4% (below the 20% "well-meshed" threshold) with only 129 principled splices.

### Branch rating strategy
- 138 kV base: 250 MVA (Texas-2k calibrated, physically correct)
- SPL T-junctions: 4× tier = 1000 MVA (env var SPL_MULT, default 4)
- Bridge-load compensation: downstream_load / 3 (env var BRIDGE_DIVISOR, default 3)
- Plant outlet stubs: 999k (generator PMax is real constraint)
- 345 kV: all 1200→2400 except WESTEX (L1594_1601_345, dynamically detected by name)
- No 999k SPL hack — explicit ratings only
